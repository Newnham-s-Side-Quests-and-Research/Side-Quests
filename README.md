# Newnham's Side Quests

I am Lewis Newnham. This is where I keep my engineering portfolio and the projects I want to explore.

The work covers autonomous systems, software, AI and quantitative research. Each project starts with a question and a plan for testing it.

## What you will find

The projects folder contains twelve project folders. Each one points to its original portfolio documents, its plan and its engineering pack. The engineering packs describe the proposed design and how I intend to test it.

The source folder contains the original portfolio. The plans folder contains the project plans. The HTML plans folder contains versions that can be opened in a browser after downloading the repository.

## Where things stand

The drone is an earlier build. I am working to recover its original files and evidence so I can distinguish what was built and tested from what was planned.

Most other projects are proposals. The Workflow Evaluation Harness now has an initial local implementation that has been tested with a small set of synthetic cases. Its results do not establish real world accuracy.

The aim is to build and test the projects in stages. I will add code, results and evidence as the work progresses.
