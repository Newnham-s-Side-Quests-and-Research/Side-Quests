# Verification record

The current checks run locally with synthetic data. The automated suite runs in the project folder. It can also be run from a clean temporary copy. The dashboard checks use a local loopback connection and require no external network. The suite covers register validation, duplicate records, unknown references, hash changes, missing files, path escapes and rights states.

The rigid body tests cover balanced hover, a rotated thrust direction, the first order motor response, rotor moment signs, constant angular rotation and a discrete free fall case. These checks do not establish accuracy for all flight conditions. The illustrative parameter values have not been measured from the original aircraft.

The controlled rigid body checks compare a small set of seeded target tracking runs, exercise loss of one motor command and verify that a singular motor allocation is rejected. The C position calculation has an optional native test suite that checks known values, invalid inputs and agreement with the Python calculation throughout a simulated flight. These checks cover the chosen cases only. The controlled example uses perfect horizontal state and attitude from the model and does not establish real flight performance.

The connected navigation checks exercise a route around static blocked cells, an assumed wind that drives the point model into a blocked cell, a grid exit and a map with no route. A segment and box check covers movement between simulation samples. The final segment is not separately checked against blocked cells if the flight model ends at ground contact. Waypoint arrival uses ideal simulated position and velocity. These checks do not include a vehicle footprint, map uncertainty or dynamic collision avoidance. The dashboard displays a sampled replay and the command line output retains the full trace. The final replay sample occurs before a detected stop.

The signal tests cover a hand calculated motion step, repeatability with a fixed seed, altitude bias, missing altitude samples, output bounds and invalid configuration. They also check a free fall example, integral holding, ideal pressure conversion, ideal motion readings and simulated link outages.

The vertical estimator is checked against hand calculated prediction and observation updates. Its pressure derivative is compared with a numerical approximation. The tests cover rejected outliers, invalid inputs, covariance checks and a deterministic synthetic replay with missing position samples.

The grid planner is compared with an independent breadth first search over all 128 obstacle arrangements in a small grid. The image detector is checked against synthetic pixels with known regions and noise. The telemetry checks preserve missing signals and label unmodelled hardware as unknown.

The three dimensional grid planner is compared with an independent breadth first search over all 64 obstacle arrangements in a small grid. The mission checks cover movement limits, route completion, unavailable position, no route and an incomplete run. Playwright checks the mission playback and position loss display at phone, tablet and desktop sizes in Chrome.

The closed loop checks cover ten deterministic seeds, expected controller inputs, missing observations, a missing motion signal, a rejected pressure outlier and operation before the first accepted observation. The healthy fixture stayed within the stated synthetic test tolerance for those seeds. The local dashboard endpoints and unsupported requests were also checked. Scenario totals and three cell power calculations were checked against hand calculated examples and the deterministic fixtures. Controller terms and filter innovation calculations were checked against the recorded trace. Playwright checked scenario selection, playback, displayed calculations and downloaded data at phone, tablet and desktop sizes in Chrome. Screenshots are retained locally. The integration checks run the components on the same synthetic scenario. The clean copy produced 50 signal steps, 50 estimates, 50 telemetry snapshots, a route of 12 grid steps and one synthetic image region. The report retains the input configuration and reports a missing route or image detection explicitly. The planner and vision detector are not connected to the closed vertical control loop.

These checks establish behaviour for the cases tested. They do not prove all possible inputs, real sensor behaviour, wireless communication, stability in flight or the behaviour of the missing original controller. Independent engineering review remains outstanding.
