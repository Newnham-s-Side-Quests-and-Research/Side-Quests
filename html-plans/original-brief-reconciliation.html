Original portfolio to engineering pack: reconciliation

Original brief reconciliation

This is a planning cross check against the 12 original technical briefs and case studies. It is not evidence that any project is implemented, verified or approved. For each project, the linked pack is the current design baseline; the original remains the source of the broader research ambition. Requirements and open decisions must be reviewed before implementation. The full original case studies, scenarios, human decision points and evidence requirements continue to apply where relevant.

Project First release in pack Original ambition retained for later or dependent on discovery
01 Drone Inventory, claim classification, architecture, rights review and conditional software in the loop tests. Recover flight and bench records, firmware, PCB, CAD, telemetry and app evidence; no flight claim without original support. Controller testing depends on actual files.
02 Aegis Reduced order dynamics, baseline, fixed/innovation monitoring and bounded simulated degraded operation. Adaptive monitoring, possible six degree of freedom model and expanded correlated fault and miscalibration experiments.
03 Infra Resilience Synthetic plant, injected faults, threshold comparison, ranked evidence and missing data cases. Broader motor, sensor, communications and software timing fault combinations and engineer review evaluation. No certified plant protection.
04 Proof AI Synthetic fixtures, deterministic adapter, independent rules and review state. OCR and model only/rules only/hybrid comparison; confidence calibration, abstention and errors that are internally consistent but wrong.
05 Invariant Ops Domain invariants, durable state, idempotency, outbox, reconciliation and crash testing. Synthetic legacy API adapters and expanded commit, acknowledgement, retry, schema version and restart campaigns.
06 Exchange Lab Single threaded reference engine, deterministic matching, replay and differential testing. Optimised candidates, full adversarial workload matrix and p50/p99/p99.9 latency and memory analysis on documented hardware.
07 Alpha Validity Null market generator, strategy universe and leakage resistant temporal baseline. Weak signal markets, statistical power, regime and cost sensitivity and licensed historical data only if rights allow.
08 Freight Audit Explicit synthetic tariff and deterministic rating with evidence linked review. Compare manual style sampling, rules and optional model extraction from unstructured clauses; measure exact amounts, false disputes and review effort.
09 Delivery Matching Synthetic receipt/invoice matching and human reviewed credit proposals. Compare manual, rules and optional free text extraction; measure credit precision/recall, short payment risk and approver edits.
10 Maintenance Triage Synthetic reports, conservative safety escalation, durable review queue and failure paths. Compare rules only, model only and combined designs; investigate duplicates, multi unit incidents and review workload. A test cannot guarantee safety.
11 Company Hub Synthetic source records, access filtered retrieval, reviewed entity links and traceable extractive briefings. Optional model assisted briefing and synthetic read only connectors; broader access leakage and entity resolution study. Real data needs separate authority and assessment.
12 Evaluation Harness Offline deterministic replay, score and gate mechanics, planted defects and human decision. Repeat trials, uncertainty, cost/latency reporting and model adapters; measure regression detection and false blocks on reviewed test sets.

Release interpretation

A first release gate covers only the stated first release requirements. Completion of later milestones must be verified separately. For every deferred item, record an owner, dependency and reason when a project is started. Do not translate a planned method into a claimed result or a simulation into physical validation.
